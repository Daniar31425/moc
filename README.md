# AlemCourse

AlemCourse — MVP массового онлайн-курса, который за один запрос создаёт короткий урок под тип учащегося и выбранную сложность.

## Проблема, пользователь и ценность

Одинаковое объяснение темы часто слишком простое для студента или слишком сложное для школьника. Целевые пользователи MVP — школьники и студенты, которым нужно быстро понять конкретную тему. Ценность решения: за 30 секунд получить адаптированное объяснение, пример и один вопрос для самопроверки.

## Единственный главный сценарий

1. Пользователь вводит тему.
2. Выбирает: школьник или студент; начальная, средняя или продвинутая сложность.
3. Нажимает «Создать микроурок».
4. Получает объяснение, пример и проверочный вопрос на одном экране.

До стабильной работы этого сценария не добавляются другие функции.

## Обязательное и необязательное

Обязательно для MVP: один экран, выбор аудитории и сложности, генерация микроурока, обработка загрузки/успеха/ошибки, серверный OpenAI API, mock-режим для демо, фиксированный контракт и отсутствие секретов в Git.

Необязательно и исключено до завершения MVP: регистрация, каталог курсов, хранение прогресса, база данных, видео, сертификаты, рейтинги, кабинет преподавателя, платежи и многоурочная программа.

## Архитектура и технологии

```text
React/Vite :5173
      │ POST /api/v1/lessons/generate
      ▼
FastAPI :8000
      │ Responses API (Hour 2)
      ▼
OpenAI
```

- Frontend: React + Vite, обычный CSS, `fetch`.
- Backend: Python + FastAPI + Pydantic + Uvicorn.
- AI: официальный Python SDK OpenAI и Responses API; структурированный результат преобразуется в контракт v1.
- Хранение: отсутствует — база данных для главного сценария не нужна.
- Резерв: `USE_MOCK=true` сохраняет демонстрацию без внешнего API.

Codex выступает техническим руководителем: фиксирует архитектуру и контракт, создаёт каркас, помогает с проверками и документацией. OpenAI API используется только на backend для генерации содержания микроурока; API-ключ никогда не передаётся в браузер.

## Структура репозитория и владение

```text
backend/                 # Данияр: FastAPI, OpenAI, серверные тесты
  app/main.py
  tests/test_api.py
frontend/                # Канат: React UI и вызовы API
  src/main.jsx
  src/styles.css
docs/
  api-contract.md        # Данияр: единственный источник истины
  hourly-report.md       # Данияр: контрольный отчёт каждый час
.env.example             # Данияр: перечень переменных без секретов
.gitignore
README.md
```

| Область | Владелец | Правило |
|---|---|---|
| `backend/` | Данияр | Канат не меняет |
| `frontend/` | Канат | Данияр интегрирует через контракт |
| `docs/api-contract.md` | Данияр | сначала документ, затем код и сообщение Канату |
| Общие файлы и merge | Данияр | контрольные коммиты в `main` |
| Демо-сценарий | Канат | проверяет loading/success/error |

Ветки: `main` — только проверенные checkpoints, `backend` — работа Данияра, `frontend` — работа Каната.

## Переменные окружения

Скопируйте `.env.example`; реальные значения храните только локально.

| Переменная | Где | Назначение |
|---|---|---|
| `OPENAI_API_KEY` | backend | секретный ключ OpenAI; только окружение |
| `OPENAI_MODEL` | backend | модель генерации; по умолчанию `gpt-5-mini` |
| `USE_MOCK` | backend | `true` для резервного mock-режима |
| `BACKEND_HOST`, `BACKEND_PORT` | backend | адрес сервера |
| `FRONTEND_ORIGIN` | backend | разрешённый CORS origin |
| `VITE_API_BASE_URL` | frontend | URL backend |
| `VITE_API_TIMEOUT_MS` | frontend | таймаут запроса, мс |

## Запуск backend

PowerShell:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Проверка:

```powershell
curl.exe http://localhost:8000/api/v1/health
python -m pytest -q
```

## Запуск frontend

Во втором терминале:

```powershell
cd frontend
pnpm install
pnpm run dev -- --host 127.0.0.1
```

Если `pnpm` не установлен, те же команды можно выполнить через `npm install` и `npm run dev -- --host 127.0.0.1`. Откройте `http://localhost:5173`. Production-проверка: `pnpm run build`.

## API-маршруты

- `GET /api/v1/health` — готовность backend.
- `POST /api/v1/lessons/generate` — создать адаптивный микроурок.

Полные схемы, ошибки, CORS и примеры: [`docs/api-contract.md`](docs/api-contract.md).

## Текущий статус

Архитектурная фаза: frontend и backend запускаются, главный сценарий работает с mock-ответом. Реальная интеграция OpenAI — следующая задача Данияра, без изменения контракта.

Известные ограничения: нет хранения данных; один урок и один вопрос; `kk` зафиксирован контрактом, но качество mock-текста не локализовано; внешний API зависит от сети и лимитов.

## Вклад команды

- Данияр: архитектура, backend, OpenAI API, интеграция, тесты, merge, контрольные коммиты и отчёты.
- Канат: frontend, состояния интерфейса, вызов API по контракту и демонстрационный сценарий.

## Инструкция для демонстрации

1. До выступления запустить оба приложения и открыть `GET /api/v1/health`.
2. В интерфейсе оставить стабильный пример: «Законы Ньютона», «Школьник», «Начальная».
3. Нажать «Создать микроурок», показать объяснение, пример и вопрос.
4. Подчеркнуть, что смена аудитории или сложности меняет содержание через OpenAI.
5. При проблеме с интернетом включить `USE_MOCK=true` и повторить тот же сценарий.

Пятый час используется только для репетиции, отправки и исправления ошибки, полностью блокирующей показ.
